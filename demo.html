Setup

1

Link the stylesheet and preload the font

Place style.css and the fonts/ folder in your project, then add these two lines to your <head>:

<!-- in <head> --> <link rel="stylesheet" href="style.css"> <link rel="preload" href="fonts/Untitled.woff2" as="font" type="font/woff2" crossorigin="anonymous">
Adjust paths if your CSS file or fonts folder live in a different directory relative to your HTML.
2

Insert the icon in your HTML

Apply the class icon-uae-dirham to a <span> and include the Unicode character :

<span class="icon-uae-dirham">&#xf000;</span>

Add aria-hidden="true" when the icon is decorative (no meaningful text around it):

<span class="icon-uae-dirham" aria-hidden="true">&#xf000;</span>
3

Size with CSS

Control the icon size using font-size in your own CSS — the icon scales with it:

.my-icon { font-size: 2em; /* or any px / rem value */ color: #c4922a; /* optional color */ }
